# Bot arayüzü — uygulama planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bot'u CustomTkinter penceresinden yönetmek: başlat/durdur, canlı istatistik, zamanlı tuşlar, ayarlar, mesaj akışı, ölünce Türkçe konuşma.

**Architecture:** `gui.py` pencereyi açar, `bot.main_loop` ve `bot.hotkey_loop`'u thread'de çalıştırır; ikisi aynı `BotState` ve `cfg` sözlüğünü paylaşır. `bot.py` mesajları `say()` ile bir kuyruğa da koyar; pencere kuyruğu okur. `bot.py` customtkinter'a bağımlı olmaz ve tek başına çalışmaya devam eder.

**Tech Stack:** Python 3.12, customtkinter, unittest/pytest, Windows System.Speech (PowerShell).

**Spec:** `docs/superpowers/specs/2026-11-06-gui-design.md`

## Global Constraints

- `bot.py` `python bot.py` ile eskisi gibi çalışır; `customtkinter` import etmez.
- Varsayılan ölüm cümlesi: `Sen bir malsın Fethi`; config anahtarı `death_say`.
- Tuş kaydı biçimi: `{"key": "1", "every_sec": 2, "when": "fight"}`; `when` ∈ `"fight"`, `"always"`.
- Eski `skill_keys` biçimi (`["1", "2"]`) → `{"key": k, "every_sec": 0, "when": "fight"}`.
- Mesaj kutusu son 200 satırı tutar; kuyruk 200 ms'de bir, istatistik 1 sn'de bir okunur.
- Pencere ~420×640, koyu tema.
- Testler: `python -m pytest tests -q` (bugün 23 test geçiyor; hiçbiri bozulmamalı).

## Review Focus

- Tuş adı büyük harfle yazılır ("F1", "TAB") → pydirectinput küçük harf ister; kayıtta küçük harfe çevrilir (Task 4 testi).
- Türkçe karakterli / tırnaklı ölüm cümlesi ("Fethi'nin") → PowerShell'e bozulmadan ulaşır; metin base64 UTF-8 olarak geçirilir (Task 3 testi).
- Negatif ya da sayı olmayan süre/yarıçap, boş pencere adı, bilinmeyen tuş → reddedilir, eski değer kalır (Task 4 testi).
- Eski liste biçimindeki `skill_keys` olan config → bot çökmeden çalışır (Task 2 testi).
- Bot dövüşteyken pencere kapatılır → threadler biter, program asılı kalmaz (Task 5 elle deneme).
